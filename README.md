
# Space-Invaders-Java
A version of Space Invaders create to help learn about Object Oriented Programming concepts and Java Swing.
<img width="505" height="529" alt="spaceinvaders" src="https://github.com/user-attachments/assets/28a04a01-b380-4706-8e6a-929f7eeb5cd0" />  
To run the program:  

1: Clone the repository  
2: Open the folder in Visual Studio  
3: Ensure JDK is installed  
4: Run App.java  
  
Controls:  

<- -> | move  
SPACE | shoot
